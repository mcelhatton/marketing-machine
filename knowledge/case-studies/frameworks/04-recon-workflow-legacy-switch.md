# Case Study Outline: Switching from Legacy Recon Tools to MDD Recon Workflow

**Product:** Recon Workflow (powered by LocateIQ)
**Angle:** Inventory Cashflow — "A $40K car sitting in recon is dead capital." Framed as a switcher story.
**Target personas:** Used Car Manager (primary), Sales Manager (primary), GM, Owner
**Follow:** `00-master-case-study-framework.md` for structure, voice, SEO, and checklist.

## Story Arc
The dealership already had recon software — and cars still got stuck. The old tool depended on someone remembering to update statuses, so the pipeline view never matched the lot. They switched to MDD Recon Workflow, and days-to-frontline dropped because the system finally reflects where cars actually are.

**⚠️ Competitor rule:** Never name the legacy tool (e.g., no "Rapid Recon"). Use category language only: "traditional workflow tools," "their previous recon software," "manual status updates."

**Challenge — lead with the switcher's frustration (this is the differentiator section):**
- Hook: "They already had recon software. Cars still sat."
- Pains: the recon board said "in detail" but the car was still behind the body shop; someone has to remember to move the card, and they often don't; bottlenecks discovered days later; vendors unaccountable; paying outside auditors to find what the software should already know; every extra day = a $40K unit as dead capital while used-car apps send buyers to the next store.
- Key insight to land: **the old tool wasn't broken — it was blind.** It tracked statuses people typed in, not where cars actually were.

**Solution:**
- Recon Workflow powered by **LocateIQ** — workflow auto-advances based on physical vehicle location. When the car moves from detail to photos, the system knows. No one has to remember anything.
- Features: acquisition-to-frontline tracking, bottleneck identification, vendor accountability, time-in-process visibility, reduced outside auditor costs.
- Switching note: cover migration/adoption briefly — how fast the team was live ({{detail from user}}).
